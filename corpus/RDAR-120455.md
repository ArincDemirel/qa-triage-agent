# rdar-120455: Temperature compensation table update, no regression found

## Description
Build 20 updated the thermal compensation table. Validation re-ran calibration offset
at all three setpoints to check for side effects.

## Root cause and resolution
Offset stayed within 0.03 mV of the previous build at every temperature. Table updates
of this kind only adjust the hot range above 50C. Closed, no action needed.
